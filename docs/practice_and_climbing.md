# SCRUM-43 and SCRUM-83

Start the normal game and select **Practice**. Choose any catalog game and Easy, Normal or Hard, then Play / Replay. After the shared result cue, the selection screen returns with the same game and difficulty selected. Back to Practice cancels a run; Back to Title exits. Practice does not spend week lives, award week points or advance days. The existing pause/settings overlay remains available. The list automatically includes future catalog additions.

**ARC Rock Climbing:** rotate with the configured LEFT / RIGHT keys and press ACTION to catch the highlighted next hold. Reach the flag before the timer runs out. A missed grab costs time, not an immediate life. Easy/Normal/Hard use 3/4/5 holds, increasing swing, smaller targets, and 9/8/7 seconds. The intro shows current bindings. Input is ignored before play and after the result. Available in Practice and the debug launcher; the authored week order is unchanged because the ticket specifies ARC/Recreation rather than a week slot.

Art is generated by `python tools/art/gen_rock_climbing_art.py` (Pillow): 256x144 wall, small transparent sprites, rendered through the existing 5x nearest pixel canvas. The scene represents the UC Davis ARC climbing wall, not a measured reconstruction.

Validation: `tools/test_practice_climbing.gd` covers catalog launches, difficulty, intro gating, rotation/grabbing, misses, all-tier wins/timeouts, pause, replay, obsolete callbacks and week-state isolation. Included in both web build scripts. Existing collection and presentation suites include climbing. Human gameplay/balance review remains pending.
